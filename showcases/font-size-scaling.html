Font Scaling Demonstration

Change Root (<html>) Font Size:

Fixed Pixels (px)

Behavior: Ignores the root font size completely. It is absolute.

Heading Example

This paragraph and the elements below will remain exactly the same size regardless of the buttons you click at the top.

New Item Update

Root EM (rem)

Behavior: Scales uniformly based on the document's root font size.

Heading Example

If you click "Large", this paragraph scales up perfectly because `1rem` equals the root size. It ensures consistent scaling across the whole app.

New Item Update

Relative EM (em)

Behavior: Scales relative to its immediate parent. Can compound dangerously if nested.

Heading Example

This paragraph uses `1em`. Since its parent `.card` is currently set to `16px`, it looks normal.
